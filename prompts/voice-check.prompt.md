# Prompt: Voice check a draft

**Use this when:** you have written a draft: email, post, document, message: and want it screened against your voice principles before sending or publishing.

## Prompt

Voice-check the draft below against my voice principles file.

Voice principles file: `[PATH/TO/voice-principles.md]`

Draft:

```
[PASTE DRAFT HERE]
```

Produce three blocks in this order.

### 1. RULE VIOLATIONS

List every hard rule the draft breaks. For each:

- The rule violated (quote it from the voice principles file).
- The offending sentence or phrase from the draft.
- A one-line rewrite suggestion.

If no rules are violated, write "Clean: no rule violations."

### 2. SOFTER ISSUES

List anything that does not break a hard rule but still feels off:

- Tone drift away from the stated voice.
- Hedging or qualifier stacking.
- Vague verbs that should be specific.
- Jargon, motivational clichés, AI-giveaway phrases, marketing-deck language.
- Greeting or sign-off that does not match the formality level of the context.

One bullet per issue. If none, write "No softer issues."

### 3. REWRITE

If there are any hard-rule violations, produce a clean rewrite of the full draft. Preserve the original meaning and structure exactly. Do not editorialise, do not lengthen, do not "improve" the message beyond the voice fix.

If there are no hard-rule violations, do not rewrite. Just confirm the draft passes.

### Final note

Do not flag style choices that are not in the voice principles file. This is a voice check, not a preference check. If the rules are silent on something, leave it alone.

## How to customise

- If your voice principles file is split into "hard rules" and "soft preferences," map block 1 to hard and block 2 to soft so the boundary is explicit.
- If you write for multiple audiences (work formal, peer casual, public broadcast), add the audience as an input so the check picks the right ruleset.
- The REWRITE block is the most opinionated. If you prefer suggestions only and never a full rewrite, remove block 3.
