# Case studies

This folder is reserved for case studies showing the pattern applied to specific deployments. Empty in v0.1.

A case study answers four questions:

1. What problem did the pattern solve?
2. What did the deployment look like (workstations, scheduled tasks, skills)?
3. What broke and what got fixed?
4. What time and quality changes resulted, measurably?

Each case study lives in its own subfolder with a `README.md`, redacted screenshots, and any reusable artefacts (prompts, skills, ADRs) that came out of the deployment.

Planned case studies (see ROADMAP.md):

- v0.3: A meeting-notes workstation with a transcript-to-action-items pipeline.
- v0.4: A two-person team variant.

If you have deployed the pattern and want to contribute a case study, open an Issue first to scope it. Case studies must follow the same personal-information rules as the rest of this repository: no real names, contacts, or facts.
