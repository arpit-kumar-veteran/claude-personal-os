# Deep Research

This skill runs a structured research process: fan out, fetch, verify adversarially, synthesise. It does not stop at the first plausible answer.

## When to use

- You need to act on the output. Speed matters less than accuracy.
- The question involves facts that are often misquoted (market size, regulatory rules, competitor claims).
- A counterparty has made a claim you want independently verified before accepting.
- You want a cited report, not a conversational answer.

## How it runs

### Phase 1: Scope

Before searching, restate the research question in one sentence. If the question is underspecified, ask two or three clarifying questions. A narrow, specific question produces a better report than a broad one.

State the scope:
- Core question
- Key claims to verify
- Sources that will be considered authoritative for this topic

### Phase 2: Fan-out search

Run at least three independent search angles. Examples:

- Primary: search the direct question.
- Secondary: search for critiques or counterarguments to the most common answer.
- Tertiary: search for primary sources (regulatory documents, original research, official filings) that underpin the common answer.

For each angle, note what was found, the source name, and the date.

### Phase 3: Adversarial verification

For every major claim the research is building toward, run an explicit adversarial check:

> "What is the strongest case that this claim is wrong, overstated, or outdated?"

If the adversarial check finds a credible counterargument, include it in the report. Do not bury it.

Label each claim with a confidence level: **high** (multiple independent primary sources agree), **medium** (one strong source, plausible but not cross-checked), **low** (single source, secondary, or outdated).

### Phase 4: Synthesise

Produce the report in four sections:

1. **Answer** — the direct answer to the research question in two to four sentences.
2. **Evidence** — the supporting claims, each with source name and confidence level.
3. **Counterarguments** — what the adversarial check found. If nothing credible, state that explicitly.
4. **Sources** — numbered list of every source cited, with URL or publication name and date.

### Phase 5: Flag limits

After the report, state:
- What could not be verified.
- What would change the conclusion if it turned out to be different.
- Whether any key source is behind a paywall or required registration to access.

## Boundaries

- Never omit counterarguments to make the answer cleaner.
- If primary sources contradict each other, report the contradiction. Do not pick a side without stating which source won and why.
- If the question cannot be researched adequately with available tools, say so and stop.
